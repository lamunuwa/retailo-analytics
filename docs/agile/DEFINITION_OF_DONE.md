# Definition of Done

## 1. Funcionalidad

- [ ] **Objetivo:** el código cumple el objetivo funcional.
- [ ] **Pipeline:** CI no marca errores de ruff o mypy.
- [ ] **Ejecución local:** la funcionalidad puede ejecutarse localmente siguiendo las instrucciones del README.

## 2. Pruebas y cobertura

- [ ] **Pruebas:** se agregaron o actualizaron las pruebas necesarias para la
  funcionalidad.
- [ ] **Ejecución:** `pytest` pasa correctamente.
- [ ] **Cobertura:** la cobertura total se mantiene en **80%** o más.

## 3. Configuración y seguridad

- [ ] **Secretos:** no se agregaron secretos, credenciales ni datos sensibles al
  repositorio.
- [ ] **Configuración:** toda configuración nueva usa variables de entorno cuando
  aplica.

## 4. Documentación y decisiones técnicas

- [ ] **Documentación:** se actualizó cuando la tarea cambia comportamiento,
  endpoints, arquitectura o flujo de uso.
- [ ] **IA:** se actualizó `AI_LOG.md` si se usó IA para diseñar, escribir,
  depurar o documentar la solución.
- [ ] **ADR:** se creó o actualizó un ADR cuando la tarea implica una decisión
  técnica relevante.

## 5. Integración y revisión

- [ ] **Pull Request:** la solución está integrada en la rama correspondiente
  mediante Pull Request.
- [ ] **Revisión:** el Pull Request fue revisado por al menos un integrante del
  equipo.
